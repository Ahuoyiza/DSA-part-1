Graphs

"A graph is a set of nodes (vertices) connected by edges — the most general data structure, capable of modelling any relationship between any entities."

What is a Graph?

A graph consists of vertices (nodes) and edges (connections between nodes). Unlike trees, graphs have no root, no parent-child hierarchy, and edges can form cycles. A graph can be directed (edges have direction, like a one-way street) or undirected (edges go both ways). Edges can also carry weights — a number representing cost, distance, or time.

Analogy

A graph is a city road map. Intersections are vertices, roads are edges, and distances are weights. A one-way street is a directed edge. A motorway connecting two cities symmetrically is undirected. Every routing problem — Google Maps, flight paths, package delivery — is a graph problem at its core.

Adjacency List vs Adjacency Matrix

Every graph needs a representation. The two dominant choices trade off memory against edge-lookup speed. For most real-world graphs (which are sparse — few edges relative to possible edges), the adjacency list wins on space. For dense graphs where you frequently ask "is there an edge from A to B?", the matrix wins.

Watch out

A social network with 1 billion users would need a 1 billion × 1 billion adjacency matrix — roughly 1018 entries. Since each user averages ~300 friends, the matrix is 99.999997% zeros. Facebook uses an adjacency list (and a distributed graph database) for exactly this reason.

Graph with Adjacency List

JavaScript 
class Graph {
  constructor() {
    this.list = new Map();  // vertex → [neighbours]
  }

  addVertex(v) {
    if (!this.list.has(v)) this.list.set(v, []);
  }

  addEdge(u, v, weight = 1) {   // undirected
    this.list.get(u).push({ node: v, weight });
    this.list.get(v).push({ node: u, weight });
  }

  neighbours(v) {
    return this.list.get(v) ?? [];
  }

  hasEdge(u, v) {                // O(degree)
    return this.neighbours(u).some(e => e.node === v);
  }
}

const g = new Graph();
['A', 'B', 'C'].forEach(v => g.addVertex(v));
g.addEdge('A', 'B', 4);
g.addEdge('B', 'C', 2);
TypeScript 
type Edge = { node: string; weight: number };

class Graph {
  private list = new Map<string, Edge[]>();

  addVertex(v: string): void {
    if (!this.list.has(v)) this.list.set(v, []);
  }

  addEdge(u: string, v: string, weight: number = 1): void {
    this.list.get(u)!.push({ node: v, weight });
    this.list.get(v)!.push({ node: u, weight });
  }

  neighbours(v: string): Edge[] {
    return this.list.get(v) ?? [];
  }

  hasEdge(u: string, v: string): boolean {
    return this.neighbours(u).some(e => e.node === v);
  }
}
Python 
from collections import defaultdict

class Graph:
    def __init__(self):
        self.list = defaultdict(list)

    def add_edge(self, u, v, weight=1):  # undirected
        self.list[u].append((v, weight))
        self.list[v].append((u, weight))

    def neighbours(self, v):
        return self.list[v]

    def has_edge(self, u, v):          # O(degree)
        return any(node == v for node, _ in self.list[u])

g = Graph()
g.add_edge('A', 'B', 4)
g.add_edge('A', 'D', 7)
g.add_edge('B', 'C', 2)

for neighbour, w in g.neighbours('A'):
    print(f'A → {neighbour}  (weight {w})')

Where Graphs Show Up

Google Maps

Every intersection is a vertex, every road is a weighted edge. Maps runs Dijkstra's (or A*) on this graph to find the shortest path — processing millions of vertices in under a second.

Social Networks

Instagram, LinkedIn, and Twitter are directed graphs. Followers are directed edges. "Degrees of separation" is a BFS traversal. Friend recommendations use graph clustering algorithms.

Internet Routing

The internet is a massive weighted graph. BGP (Border Gateway Protocol) runs a distributed shortest-path algorithm across autonomous systems to route your packets from Lagos to London.

Dependency Resolution

npm, pip, and cargo all model packages as a directed acyclic graph (DAG). Installing a package runs topological sort to determine the correct installation order without circular dependencies.
