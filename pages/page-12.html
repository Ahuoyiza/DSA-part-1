Lesson 12

Trees & Binary Trees

"A tree is a hierarchical data structure where each node has at most one parent and zero or more children — used wherever data has natural parent-child relationships."

What is a Tree?

A tree is a collection of nodes connected by edges, with one special node at the top called the root. Every node except the root has exactly one parent. Nodes with no children are called leaves. A binary tree adds one constraint: each node may have at most a left and a right child — no more.

Analogy

A tree is like a company org chart. The CEO (root) manages VPs (children), each VP manages managers, and individual contributors (leaves) are at the bottom. Information flows along edges — never sideways between peers at the same level.

Tree Traversal

The order in which you visit nodes matters. There are three standard traversals for binary trees — each produces a different sequence from the exact same tree:

  • In-order (Left → Node → Right) — produces sorted output on a BST
  • Pre-order (Node → Left → Right) — used to copy or serialise a tree
  • Post-order (Left → Right → Node) — used to safely delete a tree
Insight

In-order traversal of a valid BST always produces a perfectly sorted sequence. This is the trick behind converting a BST to a sorted array in O(n) — and why interviewers ask you to verify a BST by checking that its in-order output is ascending.

Tree Node & Traversals

JavaScript 
class TreeNode {
  constructor(val) {
    this.val   = val;
    this.left  = null;
    this.right = null;
  }
}

// Left → Node → Right  (sorted output on BST)
function inOrder(node, result = []) {
  if (!node) return result;
  inOrder(node.left, result);
  result.push(node.val);
  inOrder(node.right, result);
  return result;
}

// Node → Left → Right  (copy / serialise)
function preOrder(node, result = []) {
  if (!node) return result;
  result.push(node.val);
  preOrder(node.left, result);
  preOrder(node.right, result);
  return result;
}

// Height of tree — O(n)
function height(node) {
  if (!node) return 0;
  return 1 + Math.max(height(node.left), height(node.right));
}
TypeScript 
class TreeNode<T> {
  val:   T;
  left:  TreeNode<T> | null = null;
  right: TreeNode<T> | null = null;
  constructor(val: T) { this.val = val; }
}

function inOrder<T>(
  node: TreeNode<T> | null,
  result: T[] = []
): T[] {
  if (!node) return result;
  inOrder(node.left, result);
  result.push(node.val);
  inOrder(node.right, result);
  return result;
}

function height<T>(node: TreeNode<T> | null): number {
  if (!node) return 0;
  return 1 + Math.max(height(node.left), height(node.right));
}
Python 
class TreeNode:
    def __init__(self, val):
        self.val   = val
        self.left  = None
        self.right = None

def in_order(node, result=None):
    if result is None:
        result = []
    if not node:
        return result
    in_order(node.left, result)
    result.append(node.val)
    in_order(node.right, result)
    return result

def height(node):
    if not node:
        return 0
    return 1 + max(height(node.left), height(node.right))

def count_nodes(node):
    if not node:
        return 0
    return 1 + count_nodes(node.left) + count_nodes(node.right)

Where Trees Show Up

Browser DOM

Every web page is a tree. The browser traverses it post-order to calculate layout (children must be sized before parents) and pre-order to paint (parents render before children).

File Systems

Every directory tree on your computer is a tree. The Unix find command is DFS. macOS Spotlight indexes files by traversing this tree and building a hash index.

Compiler ASTs

Every line of code you write is parsed into an Abstract Syntax Tree. TypeScript, Babel, ESLint, and Prettier all walk this tree to transform, lint, or format your code.

JSON Parsing

JSON's nested objects form a tree. JSON.parse() builds an in-memory tree, and every data.user.address.city access traverses a path from root to leaf.
