Lesson 16

BFS & DFS

"BFS explores level by level using a queue; DFS dives as deep as possible using a stack — two fundamental strategies for visiting every node in a graph or tree."

Breadth-First Search (BFS)

BFS visits nodes level by level — all nodes at distance 1, then all at distance 2, and so on. It uses a queue (FIFO): add a node's unvisited neighbours to the back of the queue, take the next node from the front. Because it fans out evenly, BFS is guaranteed to find the shortest path in an unweighted graph.

Analogy

BFS is like dropping a stone in water — the ripples spread outward in concentric rings, hitting every point at the same distance before moving further out. Nearest nodes are always found first, which is why BFS guarantees shortest paths in unweighted graphs.

Depth-First Search (DFS)

DFS follows one path as deep as possible before backtracking. It uses a stack — either the call stack (recursion) or an explicit stack. DFS is the natural choice for problems that involve exploring all possible paths, detecting cycles, or topological sorting, rather than finding the shortest one.

BFS vs DFS — When to use which

Use BFS when you need the shortest path in an unweighted graph, or want to find nodes close to the source first — social network degrees, web crawlers. Use DFS when you need to explore all paths, detect cycles, solve mazes, perform topological sorting, or when memory is tight (DFS uses O(h) space vs BFS O(w) — depth vs width).

BFS & DFS Implementation

JavaScript 
// BFS — shortest path, level-order  O(V+E)
function bfs(adjList, start) {
  const visited = new Set([start]);
  const queue   = [start];
  const order   = [];

  while (queue.length) {
    const node = queue.shift();   // dequeue front
    order.push(node);

    for (const nb of adjList.get(node) ?? []) {
      if (!visited.has(nb)) {
        visited.add(nb);
        queue.push(nb);
      }
    }
  }
  return order;
}

// DFS recursive — explore all paths  O(V+E)
function dfs(adjList, node, visited = new Set()) {
  visited.add(node);
  const order = [node];

  for (const nb of adjList.get(node) ?? []) {
    if (!visited.has(nb))
      order.push(...dfs(adjList, nb, visited));
  }
  return order;
}

// DFS iterative (explicit stack)
function dfsStack(adjList, start) {
  const visited = new Set();
  const stack   = [start];
  const order   = [];

  while (stack.length) {
    const node = stack.pop();
    if (visited.has(node)) continue;
    visited.add(node);
    order.push(node);
    for (const nb of adjList.get(node) ?? [])
      if (!visited.has(nb)) stack.push(nb);
  }
  return order;
}

type AdjList = Map<string, string[]>;

function bfs(graph: AdjList, start: string): string[] {
  const visited = new Set<string>([start]);
  const queue: string[]  = [start];
  const order: string[]  = [];

  while (queue.length) {
    const node = queue.shift()!;
    order.push(node);
    for (const nb of graph.get(node) ?? []) {
      if (!visited.has(nb)) {
        visited.add(nb);
        queue.push(nb);
      }
    }
  }
  return order;
}

function dfs(
  graph: AdjList,
  node: string,
  visited: Set<string> = new Set<string>()

  const order: string[] = [node];

}
Python 
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue   = deque([start])   # O(1) popleft
    order   = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for nb in graph.get(node, []):
            if nb not in visited:
                visited.add(nb)
                queue.append(nb)
    return order


def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    order = [node]
    for nb in graph.get(node, []):
        if nb not in visited:
            order.extend(dfs(graph, nb, visited))
    return order


# Example graph as adjacency dict
g = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F', 'G'],
}
print(bfs(g, 'A'))   # ['A','B','C','D','E','F','G']
print(dfs(g, 'A'))   # ['A','B','D','E','C','F','G']

Where BFS & DFS Show Up

Social Network Degrees

LinkedIn's "2nd degree connection" feature is BFS stopping at depth 2. Facebook's "people you may know" explores up to depth 3. BFS guarantees the closest connections surface first.

Web Crawlers

Googlebot uses BFS to crawl the web — starting from seed URLs and spreading outward level by level. DFS would risk diving infinitely deep into a single site before finding others.

Compiler Topological Sort

DFS on a dependency graph produces a topological ordering — the valid build order for a project. Webpack and Rollup use this to bundle modules in the correct sequence.

File System Search

find and grep -r use DFS to recursively search directories. VS Code's file search uses DFS to index your project. The call stack mirrors the directory nesting depth.
