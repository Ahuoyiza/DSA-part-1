Lesson 14

Heaps & Priority Queues

"A heap is a complete binary tree satisfying the heap property — max-heap: every parent ≥ its children; min-heap: every parent ≤ its children. It is the engine behind the priority queue."

What is a Heap?

A heap is a complete binary tree — every level is fully filled except possibly the last, which fills left-to-right. It enforces one rule: the heap property. In a max-heap, every parent is greater than or equal to its children, so the largest value always sits at the root. A min-heap is the mirror: smallest at the root. This guarantees O(1) access to the extremum and O(log n) insert and extract.

Analogy

Think of a hospital A&E triage queue. Patients don't wait in arrival order — the most critical case always goes to the front. When a new patient arrives, a nurse places them at the correct priority level. That's a min-heap: the lowest (most urgent) value always surfaces to the top for O(1) access.

Stored as an Array — No Pointers Needed

Because a heap is a complete binary tree, it maps perfectly onto a flat array — no left/right pointers required. For any node at index i, its children and parent are always at predictable offsets, computable with arithmetic alone.

Insight

Because the heap is stored in a contiguous array, it benefits from CPU cache locality — sequential memory access is much faster than chasing pointers. This is why heap-based priority queues outperform pointer-based tree implementations in practice, even when theoretical complexity is identical.

Min-Heap Implementation

JavaScript 
class MinHeap {
  constructor() { this.heap = []; }

  peek()  { return this.heap[0]; }          // O(1)
  size()  { return this.heap.length; }

  push(val) {                               // O(log n)
    this.heap.push(val);
    this._siftUp(this.heap.length - 1);
  }

  pop() {                                   // O(log n)
    const min  = this.heap[0];
    const last = this.heap.pop();
    if (this.heap.length) {
      this.heap[0] = last;
      this._siftDown(0);
    }
    return min;
  }

  _siftUp(i) {
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.heap[p] <= this.heap[i]) break;
      [this.heap[p], this.heap[i]] = [this.heap[i], this.heap[p]];
      i = p;
    }
  }

  _siftDown(i) {
    const n = this.heap.length;
    while (true) {
      let min = i;
      const l = 2 * i + 1, r = 2 * i + 2;
      if (l < n && this.heap[l] < this.heap[min]) min = l;
      if (r < n && this.heap[r] < this.heap[min]) min = r;
      if (min === i) break;
      [this.heap[min], this.heap[i]] = [this.heap[i], this.heap[min]];
      i = min;
    }
  }
}
TypeScript 
class MinHeap<T> {
  private heap: T[] = [];

  peek(): T | undefined { return this.heap[0]; }
  size(): number        { return this.heap.length; }

  push(val: T): void {
    this.heap.push(val);
    this._siftUp(this.heap.length - 1);
  }

  pop(): T | undefined {
    const min  = this.heap[0];
    const last = this.heap.pop()!;
    if (this.heap.length) {
      this.heap[0] = last;
      this._siftDown(0);
    }
    return min;
  }

  private _siftUp(i: number): void {
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (this.heap[p] <= this.heap[i]) break;
      [this.heap[p], this.heap[i]] = [this.heap[i], this.heap[p]];
      i = p;
    }
  }

  private _siftDown(i: number): void {
    const n = this.heap.length;
    while (true) {
      let min = i;
      const l = 2 * i + 1, r = 2 * i + 2;
      if (l < n && this.heap[l] < this.heap[min]) min = l;
      if (r < n && this.heap[r] < this.heap[min]) min = r;
      if (min === i) break;
      [this.heap[min], this.heap[i]] = [this.heap[i], this.heap[min]];
      i = min;
    }
  }
}
Python 
import heapq

# Python's heapq is always a min-heap
heap = []

# O(log n) — push
heapq.heappush(heap, 5)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)

# O(log n) — pop minimum
min_val = heapq.heappop(heap)    # 1

# O(1) — peek minimum
top = heap[0]

# O(n) — build heap from existing list
nums = [4, 8, 2, 7, 1]
heapq.heapify(nums)              # in-place, O(n)

# Max-heap trick: negate all values
max_heap = []
heapq.heappush(max_heap, -10)
heapq.heappush(max_heap, -5)
max_val = -heapq.heappop(max_heap) # 10

# K smallest elements — O(n log k)
result = heapq.nsmallest(3, [9,1,7,2,5]) # [1,2,5]

Where Heaps Show Up

OS Process Scheduling

Linux's Completely Fair Scheduler uses a red-black tree (a heap-like structure) to always run the process with the least CPU time — O(log n) schedule, O(1) pick-next.

Dijkstra's Algorithm

Google Maps finds shortest paths using Dijkstra's algorithm, which processes cities in order of tentative distance — implemented with a min-heap that gives O((V+E) log V) total complexity.

Heap Sort

Build a max-heap in O(n), then repeatedly extract the max in O(log n). The result is a sorted array in O(n log n) with O(1) extra space — no allocations beyond the input array.

Merge K Sorted Streams

Log aggregation tools merge thousands of sorted log streams by putting the current minimum of each stream in a min-heap — extracting in order across all streams in O(n log k).
