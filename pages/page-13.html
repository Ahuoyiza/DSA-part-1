Lesson 13

Binary Search Trees

"A BST is a binary tree where every left child is smaller than its parent and every right child is larger — enabling O(log n) search, insert, and delete on balanced trees."

What is a Binary Search Tree?

A BST adds a single ordering rule on top of a binary tree: for every node with value V, all values in the left subtree are smaller than V, and all values in the right subtree are larger than V. This invariant means you can eliminate half the tree at every step — exactly like binary search on a sorted array, but structured as a tree.

Analogy

Think of a phone book opened to the middle. If your name comes before the current page, you only search the left half — if after, only the right. A BST does this structurally: each node IS the midpoint of its subtree. Every comparison discards half the remaining possibilities.

Balanced vs Unbalanced

The O(log n) guarantee only holds when the tree is balanced — meaning its height is approximately log n. If you insert already-sorted values (10, 20, 30, 40…), every new node goes to the right and the BST degenerates into a linked list with O(n) operations. Self-balancing trees (AVL, Red-Black) fix this automatically after every insert.

Watch out

JavaScript's Map and Python's dict are hash tables, not BSTs. They give O(1) lookup but no sorted order. When you need sorted keys, range queries, or in-order iteration, use a BST-backed structure — in Python, sortedcontainers.SortedList fills this gap.

Insert & Search

JavaScript 
class BSTNode {
  constructor(val) {
    this.val   = val;
    this.left  = null;
    this.right = null;
  }
}

// O(log n) balanced / O(n) worst case
function insert(root, val) {
  if (!root) return new BSTNode(val);
  if (val < root.val)
    root.left  = insert(root.left, val);
  else if (val > root.val)
    root.right = insert(root.right, val);
  return root;
}

// O(log n) balanced / O(n) worst case
function search(root, val) {
  if (!root || root.val === val) return root;
  if (val < root.val) return search(root.left, val);
  return search(root.right, val);
}

// Min is always the leftmost node
function findMin(root) {
  while (root.left) root = root.left;
  return root.val;
}
TypeScript 
class BSTNode<T> {
  val:   T;
  left:  BSTNode<T> | null = null;
  right: BSTNode<T> | null = null;
  constructor(val: T) { this.val = val; }
}

function insert<T>(
  root: BSTNode<T> | null,
  val: T
): BSTNode<T> {
  if (!root) return new BSTNode(val);
  if (val < root.val)
    root.left  = insert(root.left, val);
  else if (val > root.val)
    root.right = insert(root.right, val);
  return root;
}

function search<T>(
  root: BSTNode<T> | null,
  val: T
): BSTNode<T> | null {
  if (!root || root.val === val) return root;
  return val < root.val
    ? search(root.left, val)
    : search(root.right, val);
}
Python 
class BSTNode:
    def __init__(self, val):
        self.val   = val
        self.left  = None
        self.right = None

def insert(root, val):
    if not root:
        return BSTNode(val)
    if val < root.val:
        root.left  = insert(root.left, val)
    elif val > root.val:
        root.right = insert(root.right, val)
    return root

def search(root, val):
    if not root or root.val == val:
        return root
    if val < root.val:
        return search(root.left, val)
    return search(root.right, val)

def find_min(root):
    while root.left:
        root = root.left
    return root.val

Where BSTs Show Up

Database Indexes

MySQL and PostgreSQL use B-Trees (multi-way balanced BSTs) for every indexed column. Every WHERE id = 5 query traverses one in O(log n) instead of scanning all rows.

std::map in C++

C++'s std::map is a Red-Black tree — a self-balancing BST that guarantees O(log n) on all operations and maintains keys in sorted order at all times.

Auto-complete

Suggestions in IDEs and search bars are stored in BST-backed structures (or tries). Prefix searches walk left/right to find all words beginning with your typed characters in O(log n + k).

Git Pack Index

Git's pack file index uses a sorted binary structure for O(log n) object lookup by SHA-1 hash. Every git show abc123 command performs a binary search through this index.
